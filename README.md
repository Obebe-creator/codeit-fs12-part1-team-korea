# Codeit FS12 Part1 - Team2
대한민국 각 지역의 관광지, 특산물, 축제를 한눈에 볼 수 있는 지역 소개 웹사이트
<br>
<br>

##  프로젝트 소개

본 프로젝트는
특정 대상을 소개하는 페이지라는 기획 예시에서 출발했습니다.

팀 회의 후 우리는 특정 인물이 아닌,
대한민국 자체를 하나의 주제로 선정하여
지역별 매력을 소개하는 웹사이트를 제작했습니다.

대한민국을 5개 권역으로 나누고,
각 지역의 관광지·특산물·축제 정보를 정리하여
하나의 통합된 지역 소개 사이트로 구현했습니다.

<br>

##  팀 구성 및 담당 업무

총 5개의 ‘권’으로 분담

<aside>

**윤소정** : 충청권 <br>
**김성현** : 호남권(전라권) <br>
**하성민** : 강원권 <br>
**장민주** : 영남권(경상권) <br>

<aside>

김성현 : 리팩토링 및 폰트 적용<br>

##  각 페이지 요소
- **경기도**
  - 상단 내비게이션 내 관광지 섹션 구성
  - 관광지 소개, 이미지, 연락처 정보 제공
  - 경기 지역 특산물 리스트 소개
  - 역사 인물 소개
  - 2026년 3월 축제 일정 캘린더 제공

- **강원도**
  - 행사 / 특산물 / 관광지 메뉴 구성
  - 대표 축제 소개 및 외부 공식 사이트 링크 연결
  - 강원도 대표 특산물 소개

- **충청도**
  - “충청도 와봤슈?” 콘셉트 구성
  - 03월 축제 보기 / 03월 관광지 보기 CTA 버튼 제공
  - 03월 축제 4선 구성
  - 03월 관광지 4선 구성

- **전라도**
  - 전라도 메인 페이지에서 하위 메뉴로 이동 가능
  - 기아 타이거즈 소개
  - 전라도 맛집 리스트 구성
  - 관광 명소 리스트 제공
  - 2026년 축제 일정 안내 및 외부 링크 연결

- **경상도**
  - 2026년 3월 축제 안내 캘린더 중심 구성
  - 축제 항목별 상세 설명 제공
  - 지자체 및 관광 공식 사이트 링크 연결

- **제주도**
  - 제주도 여행 안내
  - 03월 제주 축제 일정 캘린더 제공
  - 제주 축제 소개 및 외부 링크 연결
  - 제주 특산품 소개

##  느낀점
### 🧑 (팀장)김성현

> 팀 단위의 작업을 시작할 때, 여러 컨벤션을 정하고 시작했는데, 협업에 있어 고무적이었다고 생각한다.
> 페이지 위주로 디자인을 살짝 잡고 들어갔었는데 디자인 시스템이나 틀 단위로 디자인을 나누었으면 더 좋았을 것 같았다.
> PR 양식을 맞춰보며 양식에 맞지 않아 닫아도 보았다.
> 팀원들 입장에서는 이렇게까지 싶었을 수도 있었을 것 같지만 필요하다고 생각했다.
> 각 팀원의 이전 개발 경험이 달라 속도에서 차이가 있었는데, 앞뒤로 조율을 잘 했는지 모르겠다.
> 팀장으로서 전체적인 흐름을 잡고 더 잘 이끌어가고싶다.

### 👩 김남진

> 이번 프로젝트에서 수도권과 제주도를 맡았습니다.
> 처음에 파일을 잘 나눠둬서 인지 충돌이 안나서 작업이 수월하게 진행되었다고 생각하고 수정사항에 관한 규칙을 정해둬서 편했습니다.
> 각자 맡은 역할을 잘 수행해주셔서 미니 프로젝트를 잘 끝냈다 생각합니다.
> 이번 프로젝트 진행하면서 깃허브 사용법이 익숙해졌고 협업 방법에 대해서 알아가게 되었다 생각해요
> 감사합니다!

### 👩 윤소정

> 개인사정 때문에 팀 프로젝트 기획하였던 월요일에 참여하지 못해서 아쉬움이 남지만, 팀원분들께서 주제 선정 및 프로젝트 설계를 잘 해주셔서 화요일에 작업하기 편했습니다. 
> 이번 프로젝트로 html/css 를 이제 조금은 빠르게 다룰 수 있지 않나 싶습니다. 스프린트 미션1 할 때까지만 해도 어떤 식으로 레이아웃이 잡히는지 헷갈려서 시간이 오래 걸렸었는데,
> 이렇게 다 정리하며 요소 사용해보고 레이아웃도 잡아보고 해보니 머릿속에서 구조가 잡히는 것 같았습니다.
> 깃허브도 원래 git merge로 명령어 통해서 합치다보니까 브랜치가 많아지면 항상 헷갈려했는데, 이렇게 온라인에서 PR로 합치니까 훨씬 편했습니다.
> 조금 더 팀원분들께 도움이 될 수 있도록 노력해보겠습니다!


### 🧑 하성민

> 이번 미니 팀 프로젝트에서 저는 강원도 페이지의 HTML과 CSS를 담당했습니다.
> 프로젝트를 시작하기 앞서, 팀장님을 필두로 각자 역할을 분배하였고 이 때문에 git, git hub를 사용하는 과정에서 충돌이 덜 날 수 있었다고 생각합니다.
> 또한, 각자 분배한 역할을 수행하면서 의문이 있는 점을 팀원들과 편하게 소통하면서 해결하는 과정 또한 즐거웠고,
> 그 과정에서 의문 또한 해소되면서 많이 발전할 수 있었던 것 같습니다.

### 🧑 장민주

> 이번 팀 프로젝트를 통해 Git과 GitHub에 대해 더 깊이 이해하고 실제로 활용해 볼 수 있는 의미 있는 시간이었습니다.
> 팀원 및 팀장님과 함께 아이디어를 나누고 적극적으로 소통하는 과정이 즐거웠으며, 서로 도움을 주고받을 수 있었던 뜻깊은 경험이었습니다.
> 특히 각 팀원들이 본인의 역할이 끝났다고 해서 쉬는 것이 아니라, 스스로 할 일을 찾아 적극적으로 참여하는 모습을 보며 
> 협업의 진정한 의미를 다시 한 번 느낄 수 있었습니다.
> 각자 맡은 바를 책임감 있게 수행해 준 팀원분들께 감사드리며, 그 덕분에 저 또한 더 나은 팀원이 되기 위해 노력할 수 있었습니다
